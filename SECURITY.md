# Безопасность

Сервис только читает данные: он не принимает файлы, не хранит персональные данные и не требует авторизации. Входные параметры проверяются на допустимые диапазоны, размер запроса ограничен, частота запросов с одного IP ограничена.

О найденной уязвимости пишите на hello@formlab.pro с темой "Security", а не в публичные issues. Ответим в течение 3 рабочих дней.
